# Archive: the first version (withdrawn)

Everything in this folder belongs to the version of this project published in September 2026. Its main results
(a rise in bare-earth share from 1.84% to 8.43%, a net 190.3 ha, 25 degraded terraces, the saffron proximity
analysis and the rupee value at risk) were found to be an artefact of comparing two differently built satellite
products. They are withdrawn. Section 4.1 of `SS_Research_Paper.md` shows the check.

The files are kept so that the record of what was done is complete. **Do not cite numbers, figures or maps from this folder.**
